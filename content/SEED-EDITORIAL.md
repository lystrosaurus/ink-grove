# Seed Grove 内容来源与编辑记录

这六件 Seed 于 2026-09-12 由 AI 为儿童体验原创，HTML、内联插图与 SVG 封面均在本仓库创作。产品依据为 [Seed Grove 设计文档](../docs/design/Seed%20Grove｜小小思考家儿童底层认知系统设计文档.md)，它提供主题、区域、年龄原则与体验方向；作品不是对该文档的原文复制，也不是成人作品的缩写。

每件的权威来源记录保存在 `content/seeds/<id>/manifest.json` 的 `provenance`：`generatedBy: "ai"`，`sources` 指向实际设计文档，`derivedFrom: []`。本批没有从 Ink Grove 成人作品派生，不虚构书籍引用或派生关系。`related` 表示可以继续探索的真实 Seed，而非来源关系。

| Seed | 独立互动与年龄调整 |
| --- | --- |
| 我的情绪天气 | 天气窗中逐步选感受、身体信号与小照顾。6–8 岁使用三种天气和短故事；9–11 岁加入感受并存和更具体的身体线索；12–15 岁加入混合天气，区分感受、可观察信号和尚未核实的解释。 |
| 注意力小侦探 | 在标本桌筛选叶片，可收起桌边玩具、用观察框淡化无关标本，再重新观察。6–8 岁从六件标本找叶子；9–11 岁从九件中找有洞叶片；12–15 岁从十二件中同时匹配锯齿和小洞，反思筛选的帮助与遗漏。 |
| 每一个选择都有交换 | 在有限时间票下组合活动、撤回和重新分配，超额时保留原安排并指出需要交换。6–8 岁安排三十分钟；9–11 岁安排一小时并保留空白；12–15 岁在两小时中先考虑已约好的半小时，再思考最佳替代选择。 |
| 刚刚好的难 | 三条山路提供可改变的真实规律练习，可以借提示或把坡度调小。6–8 岁使用形状分组；9–11 岁使用加法与交替数列；12–15 岁观察差值的变化，并说明有限样本可能有其他延续规则。 |
| 把大问题拆小 | 把目标拆为可行动步骤、安排顺序、检查依赖、再缩小与撤回。6–8 岁为三步收桌子；9–11 岁为四步种子展，画和写可交换；12–15 岁为五步光照观察计划，包含变量与记录依赖。排计划不意味着已在现实完成任务。 |
| 错误是线索 | 可调整底座、层数与风，实际试放后展示站立或倾倒，记录最近四次条件，并比较仅改一个条件和同时改多个条件的区别。6–8 岁只调整底座；9–11 岁增加层数；12–15 岁增加侧风与单变量比较。明确这是简化模型，不代替真实物理实验。 |

作品支持 `?age=6-8`、`?age=9-11`、`?age=12-15`，缺失或未知值回退到 9–11 岁。它们不联网、不访问浏览器存储，也不发送“能力达成”或“成长完成”消息。互动只保留当前页面内存；需要留存的反思由父页面中的用户显式保存。阅读通信桥仅通过共用构建适配注入生成副本。

本目录是新增儿童原创内容，没有改动 `materials/`、成人内容副本或 `docs/design/` 原始资料。
