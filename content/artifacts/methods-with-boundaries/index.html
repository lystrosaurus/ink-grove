01 / A LABEL IS NOT AN EXPLANATION

知道偏差的名字，并不等于判断更可靠

设想一个团队准备把读书分享从每月一次改为每周一次。支持者说，多交流能促进学习；反对者说，大家已经太忙。此时贴上“确认偏误”或“损失厌恶”的标签，容易把对方变成需要纠正的人，自己的证据却没有增加。

《学会提问》和《逻辑思维》的站内解读提供两个入口：先区分主张、证据与隐含假设，再检查样本、因果与替代解释。《思考，快与慢》提醒我们审视判断过程；它不能让人从一句话诊断另一个人正在运行哪套系统。

把主张缩小

“交流有益”过于宽泛。这里真正要决定的是：在不额外挤占准备时间的情况下，是否值得增加一次自愿交流。讨论对象明确了，缺什么信息也更容易看见。

给反证留位置

若成员最缺的是独立阅读时间，再加会议可能适得其反。先询问最近没参与的人、看看准备过程，比只采访最积极的成员更接近问题。

02 / DIFFERENT KINDS OF UNKNOWN

什么时候预测，什么时候先保护退路？

《超预测》提供概率判断与更新的方向。《黑天鹅》与《反脆弱》把注意力拉向模型遗漏、极端后果和暴露结构。三者并不需要被揉成“既要乐观又要谨慎”：关键是你面对的未知是否能定义、能反馈，以及错一次会发生什么。

Good Judgment 将宽泛战略问题拆成有明确结果的小问题，再组织概率判断。这里借用的是问题可结算的设计思路，并不把预测赛事的表现外推到所有人生选择。来源：Good Judgment 的问题组说明

选一个问题，看看先需要什么。这里是一张编辑整理的使用提示，不替你作决定。

即使把第一题的概率估得很好，也不能直接回答第二题。参加人数、合同代价、退出机会是不同变量。可逆的小试验可以带回信息；不可逆承诺需要先问承受范围。这里的“风险边界”不限于金钱，也包括别人的时间、隐私与信任。

03 / THE MAP MUST ALLOW CORRECTION

事实、模型与价值，别放进同一个抽屉

1

事实可以核对

《事实》帮助检查比例、分布与时间背景。某项长期指标改善，不代表每个人的处境改善；一个坏案例也不自动推翻总体趋势。两种尺度要分别看。

2

模型需要条件

《科学革命的结构》提供审视科学共同体与知识变化的历史视角。它不意味着“每个人都有自己的真理”，也不能把任何反常现象都宣布成革命。

3

价值需要讨论

数据能告诉我们某个选择可能带来什么，不能单独决定什么值得。谁有发言权、谁承担成本，也应进入问题。不要用一个效率数字结束价值分歧。

把一本书读成
一张有边界的卡片

下次读完一件作品，留下四句话：它帮我看见了什么；需要什么条件；哪一种观察会让我降低信心；今天能承担的尝试是什么。若写不出第二句，先回到案例，而不是再收藏一个结论。

回到最初的读书会

先试一次自愿的小组讨论，约定观察参与者能否在新案例里解释一个概念。《认知天性》与《刻意练习》提醒我们，熟悉感、当下表现与能力变化并非同一回事。若没有看见转移应用，改任务或解释方式；不把出席当成学会。

这一次也许没有得出“每周最好”的结论，却能更清楚地知道下一次该问什么。这样的不确定性，比一个失去条件的漂亮答案更有用。
