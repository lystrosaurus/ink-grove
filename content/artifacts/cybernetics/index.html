CYBERNETICS — OR CONTROL AND COMMUNICATION IN THE ANIMAL AND THE MACHINE
维纳提出了一个跨越机器与生命的视角：把结果测量并返回调节环节，可以形成闭环控制；它能否稳定、是否达到目的，还取决于模型、反馈方向、增益和延迟。

01 / THE FUNDAMENTAL LOOP

控制的本质：结果必须返回系统

开环系统只是执行；闭环系统会观察结果，把误差重新送回控制器，并据此调整后续动作。

为什么“负反馈”如此重要？

“负”并不是坏，而是修正偏差：偏高就压低，偏低就抬高，让系统重新靠近目标。

THERMOSTAT
恒温器

温度偏离设定值 → 控制器启动或停止加热。

BODY
生命稳态

生理系统持续感知状态并调整，使内部环境维持可生存范围。

NAVIGATION
导航与舵控

观察当前位置与航向 → 持续修正，而不是一次性决定方向。

LEARNING
学习

行动 → 结果 → 误差 → 修正，也可以理解为一种反馈控制。

02 / INFORMATION CHANNEL

控制依赖通信，通信依赖信息质量

没有可靠的信息，系统就无法判断自身状态。噪声会污染消息，延迟会使反馈失去时效。

SIGNAL

信息

系统必须把“发生了什么”编码成可传递的消息，才能产生反馈。

NOISE

噪声

信息在传播中被干扰，接收端看到的不再是系统真实状态，控制因此可能失真。

HOMEOSTASIS

稳态

可靠测量只是条件之一。反馈方向、强度、延迟和对象动态共同决定系统是否稳定，负反馈也可能发生振荡。

BENCH NOTE / 一个会振荡的纠偏器

反馈方向正确，动作也可能过头

先把假设写成最小模型

本站假设离散系统：目标 r = 10，当前输出 y；下一步 y′ = y + k(r − y)。每次按误差的 k 倍修正，没有测量噪声、没有延迟，也没有执行器限幅。它只是用来观察增益影响的教学模型。

若初始 y = 0、k = 0.5，输出依次为 5、7.5、8.75，逐步靠近目标。这里的稳定来自这个特定方程与参数，不能只归功于“有反馈”。

同一个负反馈，换一个增益

令 k = 2，输出变成 0 → 20 → 0 → 20，误差反复跨过目标而不缩小。令 k = 2.2，则为 0 → 22 → −4.4 → 27.28，偏差幅度扩大。

误差 e′ = (1 − k)e
在此无延迟线性模型中：0 < k < 2 才收敛。

负号代表纠偏方向，稳定性还取决于整条回路。

返回现实后，多问三件事

测到的温度是真实温度，还是有偏的传感器读数？加热关掉后余热会不会继续传递？控制器命令再大，设备是否也只能提供有限功率？

加上延迟、惯性和饱和后，刚才的收敛范围不能直接照搬。现代控制教材用于澄清这个工程边界，不把这条本站方程冒充维纳书中的原例。

从仪器搬到组织时，需要增加什么？

假设客服团队把首次响应时间当设定目标。若只统计自动问候消息，它能把指标控制得很漂亮，却没有处理真实问题。需要同时观察解决时间、重复联系和用户感受，再讨论谁有权定义“解决”。人与组织会解释指标并主动适应规则，不能把他们当作只接受输入的恒温器。

反馈让信息返回，学习则可能修改模型、目标或控制方式。二者可以同时出现，却并非同义词。对结果做一次机械反应，不足以证明系统已经理解或成长。

05 / CYBERNETIC LENS

用控制论看世界：先别问“它是什么”，先问“它如何调节自己”

控制论最大的价值之一，是给复杂系统提供一套跨领域提问方式。

LENS 01

目标是什么？

先明确要调节的变量、允许范围与约束；组织中的多方目标可能冲突，不能用单一设定值隐藏分歧。

LENS 02

系统感知什么？

被测量的变量决定系统看见什么；没被感知的部分很难进入调节。

LENS 03

反馈多快？

反馈太慢，系统会持续沿错误方向前进；反馈过强，也可能产生振荡。

LENS 04

噪声在哪里？

失真、延迟和错误信号，会让控制器对不存在的问题作出反应。

LENS 05

谁在比较误差？

控制的关键不是动作本身，而是存在某种“目标—现实”的比较机制。

LENS 06

系统会学习吗？

高级系统不仅修正当前动作，还会改变自身未来的调节方式。

LENS 07

局部稳定是否伤害整体？

子系统可能把自己的指标控制得很好，却把成本转移给更大系统。

LENS 08

什么保持了秩序？

信息帮助系统调节，但不能把信息量直接等同于社会秩序，也不能忽略维持物理系统所需的能量与边界。

06 / CAUTION SIGNAL

控制并不等于“越多越好”

控制论不仅提供技术语言，也迫使我们思考：当机器、组织或传播系统拥有越来越强的反馈与调节能力时，目标由谁设定？信息是否真实？系统服务于谁？

错误目标

反馈回路可能非常高效地把系统推向一个错误目标。

指标替代现实

如果系统只能感知指标，它就可能优化数字而不是优化真实状态。

噪声与操纵

通信渠道被污染时，系统基于失真信息采取行动。

技术崇拜

一个更复杂的控制装置，并不自动意味着一个更好的社会系统。

07 / ONE-MINUTE MODEL

把《控制论》压缩成一个思考模型

反馈能帮助系统修正行动；是否学习，还要看它是否根据经验改变了后续调节规则。

从恒温器到神经系统，从学习过程到组织治理，只要存在目标、信息、反馈和调节，就可以用控制论的语言重新观察。

① TARGET系统想维持或达到什么？
② SIGNAL系统怎样知道现实发生了什么？
③ ERROR现实和目标之间差了多少？
④ FEEDBACK结果能否及时返回？
⑤ ADAPT系统只是纠偏，还是能够学习？
