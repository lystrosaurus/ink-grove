# cangjie-skill-疯传知识点

**Skill 数**：15（围绕 STEPPS 六原则）
**本地书单**：to-read/疯传-乔纳-伯杰.md（已新建）

## 核心知识点（15 个 skill）

### 全局框架
- `stepps-diagnostic` STEPPS 六维传播力诊断（优先用）
- `wom-diagnosis` 临时口碑 vs 持续口碑诊断
- `message-over-messenger` 信息设计优先于找对的人

### 社交货币 Social Currency
- `social-currency` 铸造社交货币三法

### 诱因 Triggers
- `trigger-habitat` 诱因栖息地开发
- `trigger-evaluation` 有效诱因三维评估
- `toxic-parasite` 借用竞争者广告作为自身诱因

### 情绪 Emotion
- `emotion-arousal-model` 情绪唤醒二维分类
- `emotion-injection` 注入高唤醒情绪/物理激活

### 公共性 Public
- `visibility-design` 把不可见行为转为可观察信号
- `publicity-backfire` 公共性反噬效应

### 实用价值 Practical Value
- `prospect-theory-packaging` 用前景理论包装折扣
- `rule-of-100` 折扣呈现的 100 规则

### 故事与动机 Stories
- `trojan-horse` 把品牌嵌入可传播故事
- `motivation-crowding` 避免金钱激励排挤真实分享动机

## 实践启发
- 活动没人分享：stepps-diagnostic 逐项查 → wom-diagnosis 看持续诱因 → emotion-arousal-model + visibility-design
- 预算有限：message-over-messenger 先补内容设计再考虑媒介
