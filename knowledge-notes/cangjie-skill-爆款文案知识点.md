# cangjie-skill-爆款文案知识点

**来源仓库**：kangarooking/viral-copywriting-skill（cangjie-skill 生成）
**原书**：《爆款文案》关健明 2017
**Skill 数**：14（围绕"标题→购买欲→信任→下单"四步漏斗）
**本地书单**：to-read/爆款文案-关健明.md（已新建）

## 核心知识点（14 个 skill）

### 元框架
- `copywriting-four-step-system` 文案卖货四步骤系统（优先用，负责诊断组合）

### 激发购买欲望
- `sensory-occupation` 六感描写让读者"试用"产品
- `fear-appeal` 痛苦场景 + 严重后果激发紧迫感
- `cognitive-contrast` 先写竞品弱点再写我方优势
- `usage-scenario` 设计具体使用场景
- `customer-testimonial` 精选真实评价与畅销暗示

### 赢得信任
- `authority-transfer` 权威高地位 + 高标准转移信任
- `factual-evidence` 把专业数据翻译成读者可感知事实

### 引导下单
- `price-anchor` 高价参照物让实际价显划算
- `cost-accounting` 按天成本或长期节省帮读者算账
- `justified-consumption` 把购买重构为上进/送礼/健康/孩子正当理由

### 标题写作
- `news-editorial-title` 新闻主角 + 即时性 + 重大新闻词
- `friend-chat-title` "你" + 口语词 + 惊叹词
- `practical-tip-title` 具体苦恼 + 完美结局/破解方法

## 实践启发
- 不卖货的详情页：four-step-system 检查四步 → 缺购买欲用 sensory-occupation/cognitive-contrast → 不信用 authority-transfer/factual-evidence → 贵用 price-anchor/cost-accounting
