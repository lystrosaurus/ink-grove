# Ink Grove 书单清单

> 本文件为本地视觉知识花园（Ink Grove）的书单索引，包含「现有书单」与「推荐书单」两部分。
> 现有书单依据 `materials/` 目录下已有的 HTML 作品整理；推荐书单为后续可纳入花园的候选方向与理由。

## 一、现有书单（已收录）

| 作品 | 一句话简介 |
| --- | --- |
| 人生十二法则 (12 Rules for Life) | 乔丹·彼得森以神话、心理学与道德秩序为锚，给出十二条重建个人责任与生活秩序的原则。 |
| 1% 法则 (The 1% Rule) | 阐述持续微小改进如何靠复利效应拉开人与人长期差距的边际成长法则。 |
| 巴菲特股东信 / 所有者手册 | 提炼巴菲特历年股东信中的资本配置、长期主义与所有者视角的投资信条。 |
| 认知觉醒 | 周岭剖析成长型思维与元认知，帮助读者打破惯性、主动掌控学习与生活的节奏。 |
| 认知觉醒：内在操作系统 | 将认知觉醒的方法论封装为可运行的「内在操作系统」，聚焦自我驱动与习惯重构。 |
| 控制论 (Cybernetics) | 以反馈与控制为核心，呈现系统自我调节与信息回路的跨学科基本原理。 |
| 刻意练习（实验风） | 基于安德斯·埃里克森研究，用实验化呈现说明专家级表现来自结构化刻意练习而非天赋。 |
| 刻意练习（现代版） | 以现代案例重述刻意练习框架，强调心智表征与高质量反馈在技能跃迁中的作用。 |
| 经济学的思维方式 (13 透镜实验室) | 用 13 个思维透镜拆解稀缺、激励与权衡，训练像经济学家一样看世界的能力。 |
| 卓有成效的管理者 (The Effective Executive) | 德鲁克指出成效源于时间、贡献、要事与决策的自我管理，而非职位高低。 |
| 伟大的心智模型 (The Great Mental Models) | 汇集跨学科核心心智模型，帮助在复杂问题中做出更清醒的判断与决策。 |
| 如何阅读一本书 (How to Read a Book) | 艾德勒与范多伦系统讲解检视、分析、主题阅读的层次，把阅读变成可被训练的能力。 |
| 创新者的窘境 (The Innovator's Dilemma) | 克里斯坦森揭示成熟企业为何被颠覆性创新击败，解析「做得越好越危险」的悖论。 |
| 整合思维（智识地图） | 以罗杰·马丁的整合思维呈现如何在对立方案中综合出更优的第三选择。 |
| 整合思维：个人操作系统 | 把整合思维落地为个人决策操作系统，用于日常复杂问题的方案合成。 |
| 管理决策中的判断 (Judgment in Managerial Decision Making) | 从行为决策视角揭示管理者常见的认知偏差与判断陷阱。 |
| 思维工具箱 / 逻辑思考 | 整理逻辑与批判性思维工具，提升论证辨析与理性表达的能力。 |
| 纳瓦尔宝典 (The Almanack of Naval Ravikant) | 汇集纳瓦尔关于财富、幸福与杠杆的哲思，主张以特定知识与复利式自我产品化。 |
| 彼得·林奇选股 | 以林奇的「投资选股」思路，教普通人从生活与常识出发发现优质标的。 |
| 穷查理宝典 (Poor Charlie's Almanack) | 查理·芒格的多学科智慧合集，强调逆向思考、能力圈与心理误判模型的运用。 |
| 洛克菲勒财富神话 | 以洛克菲勒的致富与经营叙事，呈现长期主义、复利与人脉资本的早期积累。 |
| 高效能人士的七个习惯 (The 7 Habits) | 柯维以原则为中心，从依赖走向独立再走向互赖，构建由内而外的效能习惯。 |
| 聪明的投资者 (The Intelligent Investor) | 格雷厄姆的价值投资经典，确立安全边际与市场波动中的理性投资框架。 |
| 麦肯锡方法 (The McKinsey Way) | 提炼麦肯锡的问题解决、结构化思考与客户沟通的高效能工作法。 |
| 当下的力量 (The Power of Now) | 埃克哈特·托利引导读者临在当下，从思维认同中解脱以安顿内在平静。 |
| 思考框架核心地图 | 以地图形式梳理通用思考框架，作为跨主题问题拆解的索引。 |
| 系统之美 / 系统思考 (Thinking in Systems) | 梅多斯以存量、流量与反馈回路揭示系统行为背后的结构成因与杠杆点。 |

## 二、推荐书单（候选收录）

| 候选作品 | 一句话推荐理由 |
| --- | --- |
| 原则 (Principles) — 瑞·达利欧 | 把决策与团队管理规则化为可复用的原则系统，与「整合思维 / 心智模型」形成互补。 |
| 思考，快与慢 (Thinking, Fast and Slow) — 卡尼曼 | 系统讲解双系统思维与认知偏差，补全花园中「判断与决策」主题的科学基石。 |
| 穷查理宝典补编：芒格传 (Poor Charlie's Almanack 扩展) | 已有决策室版本，可补入生平与年表，强化「关系与派生来源」的连贯性。 |
| 黑天鹅 / 反脆弱 (The Black Swan / Antifragile) — 塔勒布 | 补足不确定性、风险与非线性主题，与系统思考、投资框架构成闭环。 |
| 心流 (Flow) — 米哈里 | 从体验最优状态切入，与「认知觉醒 / 刻意练习」共同解释深度投入的机制。 |
| 第五项修炼 (The Fifth Discipline) — 圣吉 | 以学习型组织与系统基模深化系统思考，延展花园的「系统」分支。 |
| 活出生命的意义 (Man's Search for Meaning) — 弗兰克尔 | 从意义建构角度补足「当下的力量」之外的存在主义视角，丰富个人成长维度。 |
| 穷理查德年鉴延伸 (Benjamin Franklin) | 与「洛克菲勒 / 纳瓦尔」并置，呈现古典自律、节俭与自我完善的早期样本。 |
| 决策必读：助推 (Nudge) — 塞勒 & 桑斯坦 | 以选择架构视角补充行为决策，与「管理决策中的判断」形成实务对照。 |
| 写给大家看的设计书 (The Non-Designer's Design Book) | 提升花园内作品视觉表达的一致性与可读性，契合「保持作品独立表达」的编辑原则。 |
