# Ink Grove 书单清单

更新日期：2026-09-13。原始 HTML 仍作为资料留存，站点发布源以各作品的 manifest 与 [作品目录](../content/catalog.json) 为准。原有素材均已深化修订，推荐清单中的 **23 本书已全部制作成独立视觉作品**。

原始 materials/ 的 27 份 HTML 含 24 份书籍视觉稿（22 个不同书目）、2 份贯通与1张思考地图，保持原字节。新增23份书籍解读后，共有 **45 个书目、47份书籍作品**；连同原有其他作品及3篇新的贯通文章，Ink Grove 共 **57 件作品、10个集合、35个概念**。Seed另有6个独立互动，不混入成人书单。

“已入站”表示已有基于公开资料与本站思考的解读，不表示复制完整书籍或逐章精读。各作品区分原书主题、公开来源可确认的范围、本站原创案例和适用边界。互动中的数字是明示假设的教学示例；阅读材料不能替代原书，也不构成个人投资或治疗建议。

### 几处值得带着问题读的地方

- 《认知天性》适合检验学习方法，《超预测》适合记录可判定问题的预测。前者的困难练习需要与已有知识相匹配，后者的结论需要明确问题范围、截止时间与反馈。
- 《事实》中的数字有其资料年代。未来制稿若使用“现在”的统计，应重新核对数据、单位、分母与时间，保留书中历史观察与当前资料的区别。[作者资料注释](https://www.gapminder.org/factfulness-book/notes/)；[作者勘误](https://www.gapminder.org/factfulness-book/mistakes/)
- 《复杂》的模型展示需要说明规则与初始条件；《公共事物的治理之道》的制度比较需要交代资源、参与者和执行条件。建议同时整理成功与失败的案例。
- 《非暴力沟通》的请求应允许对方拒绝；《金字塔原理》的表达结构仍需真实证据支持。可以把一次困难对话或一页项目建议作为练习，再请对方反馈实际效果。
- 简体书名用《四千周》和《公共事物的治理之道》；“人生只有 4000 周”是常见转述，“公共事务”则容易误写正式书名。《四千周》的数量是以约八十岁人生作的示意，推荐重点在选择与承诺。
